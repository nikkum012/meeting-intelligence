# Meeting Intelligence

A GenAI-powered meeting intelligence system that transforms meeting
transcripts into structured, evidence-backed decisions, action items,
and entities.

## Project Goals

- Extract decisions from meeting transcripts
- Distinguish proposals and motions from final decisions
- Extract action items and responsible people
- Extract important entities such as people, dates, locations, and bill numbers
- Produce validated structured JSON
- Evaluate extraction quality using precision, recall, and F1

## Development

The project is developed locally in VS Code.

Google Colab is used as the temporary GPU environment for running
open-source LLM experiments.

## Data

The original evaluation dataset is private and is not included in this
public repository.
